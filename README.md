# LearnPlaywrightNew

This repository contains JavaScript and Playwright learning practice files.

## Topics Covered

- JavaScript basics
- Node.js command examples
- JavaScript identifiers
- Identifier naming styles
- JavaScript comments
- VS Code keyboard shortcuts

## How To Run JavaScript Files

Open the terminal in the project folder and run:

```bash
node chapter_01_Basics/03_JS_Commands.js
```

Example:

```bash
node chapter_03_Identifier_Literals/07_Identifier_Examples.js
```

## Notes

Invalid JavaScript identifier examples are written as comments so the files can run without syntax errors.
