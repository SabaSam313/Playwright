# VS Code Keyboard Shortcuts - Windows

## Basic Editing

| Shortcut | Action |
| --- | --- |
| Ctrl + X | Cut line when selection is empty |
| Ctrl + C | Copy line when selection is empty |
| Ctrl + V | Paste |
| Ctrl + Shift + K | Delete line |
| Ctrl + Enter | Insert line below |
| Ctrl + Shift + Enter | Insert line above |
| Ctrl + Shift + \\ | Jump to matching bracket |
| Ctrl + ] | Indent line |
| Ctrl + [ | Outdent line |
| Ctrl + / | Toggle line comment |
| Shift + Alt + A | Toggle block comment |
| Alt + Up/Down | Move line up or down |
| Shift + Alt + Up/Down | Copy line up or down |
| Ctrl + F | Find |
| Ctrl + H | Replace |
| Ctrl + S | Save file |

## Shortcut Groups

| Group | Used For |
| --- | --- |
| Search and Replace | Find, replace, and find in files |
| Multi-Cursor and Selection | Multiple cursors and selecting all occurrences |
| Editor Management | Close, split, and focus editors |
| Display | Full screen, zoom, sidebar, and panels |
| Debug | Run, breakpoints, step over, step into, and step out |
| Integrated Terminal | Toggle, create, and scroll terminal |
