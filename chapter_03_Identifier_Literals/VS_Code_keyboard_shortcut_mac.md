# VS Code Keyboard Shortcuts - Mac

## Basic Editing

| Shortcut | Action |
| --- | --- |
| Cmd + X | Cut line when selection is empty |
| Cmd + C | Copy line when selection is empty |
| Cmd + V | Paste |
| Cmd + Shift + K | Delete line |
| Cmd + Enter | Insert line below |
| Cmd + Shift + Enter | Insert line above |
| Cmd + Shift + \\ | Jump to matching bracket |
| Cmd + ] | Indent line |
| Cmd + [ | Outdent line |
| Cmd + / | Toggle line comment |
| Cmd + Shift + A | Toggle block comment |
| Option + Up/Down | Move line up or down |
| Shift + Option + Up/Down | Copy line up or down |
| Cmd + F | Find |
| Cmd + Option + F | Replace |
| Cmd + S | Save file |
